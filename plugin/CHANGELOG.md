# Changelog

Все заметные изменения в проекте **Figma Direct Importer** будут фиксироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
и проект придерживается [Семантического Версионирования](https://semver.org/spec/v2.0.0.html).

## [2.1.10] - 2026-04-18

### Исправлено
- **Syntax Error**: Исправлена ошибка компиляции `CS1022` (лишние скобки в конце файла), возникшая в версии 2.1.9.

## [2.1.9] - 2026-04-18

### Исправлено
- **API Robustness**: Исправлена ошибка `NullReferenceException` в `FigmaAPIClient` при обработке сетевых ошибок (теперь проверяется наличие `downloadHandler`).
- **Input Validation**: Добавлены проверки на пустые значения `fileId` и `nodeIds` перед выполнением запросов.

## [2.1.8] - 2026-04-18

### Исправлено
- **Empty Scene Fix**: Новые объекты теперь гарантированно получают компонент `RectTransform`. Раньше `TransformHandler` пропускал их, из-за чего сцена оставалась визуально пустой (объекты создавались с 0x0).

## [2.1.7] - 2026-04-18

### Исправлено
- **Compilation**: Исправлена ошибка `CS0104: Ambiguous reference between UnityEngine.Object and System.Object` в `FigmaParser` и `ImageHandler`.

## [2.1.6] - 2026-04-18

### Исправлено
- **Prefab Generation**: Реализован метод `UpdateOrCreatePrefab`, который был пустой заглушкой. Теперь префабы сохраняются автоматически.
- **Image Sync**: Исправлено назначение спрайтов новым объектам через `_sessionCache`.
- **Non-Destructive Update**: Плагин теперь корректно соблюдает настройку `preserveUnityNames` и не переименовывает вручную измененные объекты.
- **Manual Components Safety**: В `ImageHandler` добавлена проверка `preserveManualComponents` для предотвращения удаления пользовательских компонентов.
- **Clean Sync**: Реализовано удаление объектов (`HandleDeletedElements`), которых больше нет в макете Figma.

## [2.1.0] - 2026-04-17

### Добавлено
- **Smart Sync**: Система обновления префабов с сохранением локальных изменений и проверкой хешей слоев.
- **Auto-Prefab Pipeline**: Полная автоматизация создания префабов из Figma-фреймов.
- **Interactive Handlers**: Авто-назначение компонентов `Button`, `InputField`, `Toggle`, `ScrollRect` по именам слоев.
- **UPM Package Support**: Инструмент теперь является полноценным пакетом Unity Package Manager.
- **Improved UI/UX**: Интерфейс плагина переработан в пошаговый формат и локализован на английский.
- **Font Mapping Table**: Новая система сопоставления шрифтов Figma с ассетами TextMesh Pro.
- **Reskin Utility**: Инструмент для быстрой замены графики в префабах по ID узлов.

### Изменено
- Архитектура плагина перенесена в пространство имен `FigmaImporter.V2`.
- Логика загрузки изображений теперь использует кэширование и поддержку нескольких форматов.
