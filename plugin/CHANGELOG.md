# Changelog

Все заметные изменения в проекте **Figma Direct Importer** будут фиксироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
и проект придерживается [Семантического Версионирования](https://semver.org/spec/v2.0.0.html).

## [2.5.0] - 2026-04-21

### Добавлено
- **Система логирования (FigmaLog)**: Централизованное управление уровнем логов через настройки (Silent, Minimal, Verbose).
- **Настраиваемый масштаб изображений**: Поле `Image Export Scale` в настройках (0.5–4x).
- **Безопасность токена**: Access Token теперь хранится в `SessionState` (только в памяти).
- **Идентификация билда**: В футер окна импортера добавлена дата сборки для диагностики.

### Изменено
- `FigmaAPIClient` и `ImageSyncService` обновлены для поддержки динамического масштаба экспорта.
- Все системные сообщения и User-Agent обновлены до версии v2.5.0.

## [2.4.1] - 2026-04-20
### Добавлено
- **Deep Adaptive Layout**: Полная поддержка Figma Constraints.
- **Unity Test Suite**: Набор тестов для верификации адаптивности.
- **Prefab Root Heuristic**: Автоматическое определение корневого фрейма импорта как корня префаба.

### Исправлено
- Исправлена ошибка именования префабов "Canvas.prefab".
- Исправлены проблемы с .meta-файлами в immutable папках UPM.
