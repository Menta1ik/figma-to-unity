# 📚 База знаний: Figma-to-Unity Pipeline (v2.8.2 Stable)

Добро пожаловать в документацию проекта. Инструмент предназначен для профессионального импорта UI из Figma в Unity с поддержкой неразрушающего обновления.

## ⚡ Новое в v2.8.2
- **Turbo Batching**: Параллельное получение ссылок на изображения (5 потоков по 100 объектов), 10-20x ускорение подготовки к скачиванию на больших файлах.
- **Main Thread Safety**: Полная совместимость параллельного батчинга с Unity Main Thread.
- **Offline Mode**: Поддержка локальных `.json` файлов.
- **Improved Diagnostics**: Коды ошибок API прямо в консоли.
