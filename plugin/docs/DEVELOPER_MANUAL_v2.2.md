# 📖 Полное руководство разработчика: Figma Importer v2.2 (Stable)

Данное руководство содержит исчерпывающую информацию по настройке и эксплуатации системы импорта UI из Figma в Unity uGUI. 

---

## 🛠 1. Установка и зависимости

Плагин работает как автономный **UPM-пакет**. 

### Требования:
*   **Unity 2021.3 LTS** или выше.
*   **TextMeshPro**: должен быть установлен в проекте (Window -> TextMeshPro -> Import TMP Essential Resources).

### Шаги по установке через Git:
1.  Откройте **Window -> Package Manager**.
2.  Нажмите кнопку **+** (Add) и выберите **Add package from git URL...**.
3.  Вставьте строку: `https://github.com/Menta1ik/figma-to-unity.git?path=/plugin`
4.  Нажмите **Add**. Unity загрузит плагин и автоматически добавит зависимости (Newtonsoft JSON).

---

## ⚙️ 2. Шаг 0: Создание конфигурационных ассетов

Прежде чем открывать окно импортера, необходимо создать два файла данных в вашем проекте (`Assets/`):

### А. FigmaImporterSettings (Общие настройки)
1.  В окне **Project** нажмите правую кнопку мыши -> **Create -> Figma Importer -> Settings**.
2.  Назовите ассет, например, `MyProjectSettings`.
3.  **Настройка путей (Asset Paths):**
    *   `Base Sprites Path`: Куда сохранять скачанные картинки (например, `UI/Sprites`).
    *   `Base Prefabs Path`: Куда сохранять готовые префабы (например, `UI/Prefabs`).
4.  **Политика Non-Destructive:**
    *   `Preserve Unity Names`: Если включено, плагин не будет менять имена объектов, которые вы переименовали вручную в Unity.
    *   `Preserve Manual Components`: Если включено, плагин не будет удалять компоненты (скрипты, анимации), добавленные вами поверх импортированных объектов.

### Б. FontMappingTable (Таблица шрифтов)
1.  Нажмите правую кнопку мыши -> **Create -> Figma Importer -> Font Mapping Table**.
2.  Этот ассет связывает имена шрифтов из Figma с вашими ассетами **TextMeshPro SDF**.
3.  Вы можете заполнить её вручную или использовать кнопку **Font Audit** в окне импортера для автоматического поиска используемых шрифтов.

## 🖥 3. Работа с окном Figma Importer

Откройте окно через меню: **Window -> Figma Importer -> Dashboard**.

### Блок 1: Connection & Config (Связь)
*   **Figma URL / File ID**: Вставьте полную ссылку на макет Figma или его ID (набор символов из URL).
*   **Single Node ID**: (Опционально) Если вам нужно обновить не весь файл, а только один экран — выделите его в Figma, нажмите правой кнопкой -> **Copy link** и вставьте сюда. Плагин сам вырежет ID ноды.
*   **Access Token (PAT)**: Ваш персональный токен Figma. Получается в настройках Figma (*Settings -> Personal access tokens*).
*   **Importer Settings**: Перетащите сюда созданный ассет настроек из Шага 2А.

### Блок 2: Resources & Target (Ресурсы)
*   **Font Mapping**: Перетащите сюда таблицу шрифтов из Шага 2Б.
*   **Кнопка [Font Audit]**: Нажмите её, чтобы просканировать Figma-файл. В консоли появится список всех шрифтов. Если какого-то шрифта нет в таблице маппинга — плагин выдаст ошибку.
*   **Root Canvas**: Самое важное поле. Перетащите сюда объект **Canvas** из вашей сцены. Внутри него плагин будет строить UI.

### Блок 3: Sync & Generate (Запуск)
*   **Sync Images**: Включает/выключает скачивание картинок. Если вам нужно только поправить текст — выключите это для скорости.
*   **Force Update**: Если включено, плагин полностью пересоберет сцену с нуля, игнорируя существующие объекты и кэши.
*   **Кнопка [🚀 RUN FULL SYNC]**: Запускает процесс.

## 🏗 4. Процесс синхронизации и результат

После нажатия кнопки происходит следующее:
1.  **Парсинг JSON**: Плагин запрашивает структуру макета.
2.  **Сборка иерархии**: На сцене создаются объекты. Каждому назначается компонент `FigmaElement` (не удаляйте его!).
3.  **Batch Image Sync**: Если включены картинки, плагин запрашивает их ссылками по 25 штук (в версии 2.2 это работает стабильно и без таймаутов).
4.  **Auto-Prefab**: Как только сборка завершена, плагин **мгновенно** сохраняет результат в префаб по пути из настроек и связывает объект на сцене с этим префабом.

## 🏷 5. Подготовка макета в Figma (Маркеры)

Чтобы автоматизировать создание кнопок и инпутов, добавляйте суффиксы к названиям слоев прямо в Figma:

| Маркер | Результат в Unity |
| :--- | :--- |
| `[Btn]` | Добавит компонент **Button** и настроит `Raycast Target`. |
| `[Input]` | Добавит компонент **TMP_InputField**. |
| `[Scroll]` | Создаст структуру **ScrollRect**. |
| `[Toggle]` | Добавит компонент **Toggle**. |

## 🆘 6. Решение проблем (Troubleshooting)

### Сцена пустая или объекты не видны:
1.  **Проверьте координаты**: Элементы могут быть смещены. Посмотрите в Hierarchy — если объекты есть, но их не видно, проверьте их `RectTransform`.
2.  **Удаление старого**: Если вы работали в версии 2.1 и сцена "сломалась", удалите старый Canvas и префабы, и сделайте **чистый импорт**.
3.  **Блокировка префаба**: Если объект в Unity является частью другого префаба, Unity может запретить плагину менять его структуру. Используйте **Unpack Prefab** перед синхронизацией, если планируете сильно менять структуру.

### Ошибка 400 Bad Request:
*   В версии 2.2 это практически исключено благодаря батчингу. Если ошибка осталась — проверьте стабильность интернета или валидность Access Token.
