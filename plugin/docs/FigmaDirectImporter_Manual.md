# Figma Direct Importer | Техническая документация v2.2.5 (Hardening)

Данный инструмент предназначен для «пиксель-в-пиксель» переноса интерфейсов из Figma в Unity с использованием системы uGUI. Версия 2.2.5 включает в себя улучшенные алгоритмы стабильности, поддержку Auto Layout и систему безопасного обновления Soft-Delete.

## 📋 1. Требования (Prerequisites)
Перед установкой убедитесь, что в вашем проекте Unity присутствуют следующие компоненты:
* **Newtonsoft Json (Json.NET)**: необходим для парсинга данных Figma API.
* **TextMesh Pro**: все текстовые узлы создаются как компоненты TextMeshProUGUI.
* **Папка Editor**: файл `FigmaDirectImporter.cs` должен находиться в папке с именем `Editor` (например, `Assets/Scripts/Editor/`), иначе проект не соберется.

## 🎨 2. Гайд для дизайнеров (Figma Preparation)
Чтобы плагин правильно интерпретировал макет для uGUI, придерживайтесь следующих правил:

### Нейминг и структура
* **Осмысленные имена**: Названия слоев станут именами объектов в иерархии Unity (`btn_deploy`, `txt_player_name`).
* **Скрытые слои**: Все выключенные объекты (hidden) игнорируются при импорте.

### Текст и шрифты
* **Шрифт**: Используйте Barlow Condensed для корректного маппинга.
* **Регистр (Caps)**: Плагин поддерживает настройку Uppercase в Figma.
* **Weights**: Поддерживаются числовые веса (100–900). Убедитесь, что в Unity настроена таблица Font Weights в ассете Regular.

### Спрайты и 9-Slice
- **Умные иконки**: Если компонент (Instance) не содержит текстовых слоев, плагин считает его «Иконкой» и скачивает как PNG.
- **9-Slice Automation**: Если вы хотите, чтобы спрайт был нарезан (Sliced), добавьте к имени слоя в Figma суффикс `_9slice`. Плагин автоматически настроит `SpriteBorder` и установит `Image Type = Sliced`.

## 💻 3. Гайд для разработчиков (Workflow)
Плагин оптимизирован для поэкранного импорта через uGUI.

### Шаг 1: Настройка подключения
1. Введите Access Token и File ID макета.
2. **Node ID (ОБЯЗАТЕЛЬНО)**: Всегда указывайте ID конкретного экрана (фрейма). Импорт всего файла сразу не тестировался и может вызвать перегрузку системы.
3. **Global Font**: Назначьте ваш основной TMP Font Asset.

### Шаг 2: Управление Layout & Diagnostics
- **Auto Layout Support**: Теперь плагин автоматически транслирует Figma Auto Layout в Unity `Horizontal/Vertical Layout Group`. Рекомендуется держать эту функцию включенной для динамических списков и панелей.
- **Health Check**: Перед импортом рекомендуется запустить `Figma Importer -> Diagnostics -> Health Check`. Это проверит валидность шрифтов и готовность сцены.

### Шаг 3: Синхронизация и Soft-Delete
- **Smart Sync**: При повторном импорте существующие объекты не удаляются, а обновляются.
- **Soft-Delete Mode**: Если слой был удален в Figma, в Unity он будет выключен (`SetActive(false)`), помечен префиксом `[Orphan]` и компонентом `FigmaOrphanedElement`. Это защищает ваши ссылки на скрипты.

### Шаг 3: Процесс сборки
1. **ANALYZE LAYOUT**: проверка структуры через API.
2. **BUILD UI**: создание иерархии uGUI-объектов на сцене.
3. **FORCE SYNC IMAGES**: скачивание и настройка Sprite-ассетов.
