# 🎨 Руководство для дизайнеров: Figma Importer v2.3.1 (Stable)

Чтобы плагин корректно перенес ваш дизайн в Unity «пиксель-в-пиксель» и автоматически настроил компоненты, следуйте этим простым правилам.

---

## 1. Подготовка слоев и именование

Плагин использует **маркеры (суффиксы)** в названиях слоев для автоматического добавления Unity-компонентов.

| Суффикс | Результат в Unity | Примечание |
| :--- | :--- | :--- |
| `[Btn]` | **Button** | Добавляет компонент кнопки и настраивает Raycast Target. |
| `[Input]` | **InputField** | Для полей ввода текста (TextMeshPro). |
| `[Scroll]` | **ScrollRect** | Для прокручиваемых списков. |
| `[Toggle]` | **Toggle** | Для чекбоксов и переключателей. |
| `_9slice` | **Sliced Image** | Автоматически настраивает Sprite Border (9-Slice). |

---

## 2. Работа с Auto Layout

Версия 2.3 полностью поддерживает **Figma Auto Layout**.
*   **Vertical Layout** -> `VerticalLayoutGroup` в Unity.
*   **Horizontal Layout** -> `HorizontalLayoutGroup` в Unity.
*   **Padding & Spacing** -> Переносятся автоматически с точностью до пикселя.
*   **Alignment** -> Плагин корректно мапит выравнивание (Top Left, Center, Bottom Right и т.д.).

> [!TIP]
> Используйте `Hug Contents` и `Fill Container` в Figma — плагин транслирует это через компонент `Content Size Fitter`.

---

## 3. Спрайты и Иконки

### Прозрачность (Opacity)
Плагин корректно суммирует прозрачность самого слоя и прозрачность заливки (Fill). Если у вас слой 50% и цвет 50% — в Unity получится итоговая прозрачность 25%.

### Маски
Для создания масок в Unity используйте стандартную функцию маскирования Figma. Плагин создаст родительский объект с компонентом `Mask` и поместит содержимое внутрь.

---

## 4. Шрифты и Типографика

1.  **Используйте стили**: Старайтесь не менять настройки текста вручную для каждого блока.
2.  **Семейства шрифтов**: Убедитесь, что названия шрифтов в Figma (например, `Inter-Bold`) соответствуют тем, что есть в проекте Unity.
3.  **TextMeshPro**: Unity-разработчик настроит "Font Mapping", чтобы магия сработала.

---

## 5. Важное правило: Не удаляйте, а меняйте!

Благодаря системе **Smart Sync**, плагин узнает объекты по их внутренним ID.
*   Если вы просто передвинули кнопку или поменяли ей цвет — Unity-разработчик нажмет "Sync", и кнопка обновится, сохранив все привязанные к ней скрипты.
*   Если вы **удалили** кнопку в Figma и нарисовали рядом «такую же» — плагин воспримет это как удаление старой кнопки (логика сломается) и создание новой.
