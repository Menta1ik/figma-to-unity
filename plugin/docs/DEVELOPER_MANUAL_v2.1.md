# 🛠 Руководство разработчика: Figma Importer v2.2

Данный документ описывает процесс настройки, использования и расширения системы импорта интерфейсов из Figma в Unity.

## 📦 Установка (Installation)

Плагин полностью совместим со стандартом **Unity Package Manager (UPM)** и устанавливается через Git.

### Способ 1: Через Git URL (Рекомендуется)
1. В Unity откройте **Window -> Package Manager**.
2. Нажмите кнопку **+** в левом верхнем углу и выберите **Add package from git URL...**.
3. Введите следующую ссылку:
   `https://github.com/Menta1ik/figma-to-unity.git?path=/plugin`
4. Нажмите **Add**. Unity автоматически скачает плагин и все его зависимости.

### Способ 2: Локальная установка (Для разработки)
Если вы хотите вносить правки в сам плагин:
1. Клонируйте репозиторий к себе на диск.
2. В Package Manager выберите **Add package from disk...**.
3. Укажите путь к файлу `plugin/package.json`.

## Step 0: Подготовка проекта

Перед первым запуском убедитесь, что в вашем проекте настроены необходимые ассеты:

1.  **TextMeshPro**: Убедитесь, что в проекте установлен TMP (**Window -> TextMeshPro -> Import TMP Essential Resources**).
2.  **FigmaImporterSettings**: Создайте файл настроек. В папке `Assets` нажмите ПКМ -> **Create -> Figma Importer -> Settings**.
3.  **FontMappingTable**: Создайте таблицу шрифтов. ПКМ -> **Create -> Figma Importer -> Font Mapping Table**.

---

## Step 1: Connection & Config

В этом блоке настраивается связь с вашим проектом в Figma.

1.  **Figma URL / File ID:**
    *   В Figma: Нажмите синюю кнопку **Share** в правом верхнем углу.
    *   Нажмите **Copy link**.
    *   Или выберите конкретный экран (Frame) -> Правая кнопка -> **Copy/Paste as** -> **Copy link** (это ускорит импорт только одного экрана).
2.  **Access Token (PAT):** 
    *   Зайдите в настройки Figma -> **Personal access tokens** -> **Generate new token**.
3.  **Importer Settings:**
    *   Перетащите сюда ассет настроек. Здесь указываются пути для сохранения префабов и ресурсов.

---

## Step 2: Resources & Target

Связывание ресурсов Figma с ассетами Unity.

1.  **Font Mapping:** перетащите сюда вашу таблицу шрифтов. 
    *   Нажмите **Font Audit**, чтобы проверить, все ли шрифты из Figma имеют соответствие в Unity.
2.  **Root Canvas:** Перетащите ваш **Canvas** (или пустой объект внутри него) из иерархии сцены. 
    *   *Важно: Плагин будет строить UI именно внутри этого объекта.*

---

## Step 3: Sync & Generate

Запуск процесса импорта.

1.  **Sync Images:** включите, если нужно скачать спрайты.
2.  **Force Update:** включите, если нужно игнорировать кэши и перекачать всё заново.
3.  Нажмите зеленую кнопку **🚀 RUN FULL SYNC**.

### Что происходит при синхронизации:
1.  **Batch Downloading**: Плагин скачивает ссылки на изображения пачками по 25 штук (защита от Timeout).
2.  **Smart Update**: Объекты в сцене обновляются без удаления (сохраняются ваши скрипты и анимации).
3.  **Auto-Prefab**: После завершения сборки плагин автоматически сохраняет или обновляет префаб в папке `UI/Generated/Prefabs`.

## Рекомендации по именованию (Markers)

Используйте суффиксы в названиях слоев Figma для автоматизации компонентов в Unity:
*   `[Btn]` — создает компонент `Button`.
*   `[Input]` — создает `TMP_InputField`.
*   `[Scroll]` — создает `ScrollRect`.
*   `[Toggle]` — создает `Toggle`.

> [!IMPORTANT]
> **Неразрушаемость**: Если в настройках включен `Preserve Unity Names`, плагин не будет менять имена объектов, которые вы переименовали вручную в Unity.
