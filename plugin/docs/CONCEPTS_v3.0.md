# Концепция развития Figma to Unity Importer v3.0: Intelligent & Agent-Ready

## 🎯 Видение версии 3.0
Версия 3.0 переводит наш импортер в категорию **интеллектуальной операционной среды для UI**. Основной фокус — полная интеграция с профессиональными префабами Unity, автоматизация рутинных задач через ИИ (MCP) и максимально быстрый цикл итерации (Delta-Sync).

---

## 1. Matrix Mapping System (Визуальный маппинг)
Центльное нововведение v3.0, значительно расширяющее возможности текущего Interactive Pipeline.

*   **Mapping Interface:** Новое окно в Editor, где визуально сопоставляются теги/компоненты Figma и конкретные префабы в вашем Unity-проекте.
*   **Deep Property Injection:** Система поддерживает интерфейс `IFigmaBindable`. Если ваш префаб (например, кастомная кнопка) реализует его, импортер автоматически свяжет ссылки на Image и Text слои Figma с полями вашего скрипта без ручного перетягивания.
*   **Variant Auto-Switch:** Автоматическая поддержка Figma Variants. Плагин распознает стейты (Hover, Pressed, Disabled) и автоматически настраивает соответствующие состояния в Unity.

## 2. Live Delta-Sync & Perpetual Cache
Мы отказываемся от медленного полного импорта в пользу мгновенной синхронизации изменений.

*   **Project Cache 2.0:** Сериализация графа узлов Figma локально в проекте Unity. 
*   **Smart Diffing:** Система сравнивает локальный слепок с актуальными данными из Figma API и обновляет только измененные свойства (цвет, текст, RectTransform).
*   **Conflict Protection:** Если разработчик изменил объект вручную в Unity, система пометит его флагом `User Override` и не будет сбрасывать эти изменения при следующей синхронизации.

## 3. Asset Intelligence & Auto-Tinting
Оптимизация производительности и ресурсов «из коробки».

*   **Dynamic Sprite Tinting:** Автоматическое определение одноцветных иконок. Плагин конвертирует их в белые маски и применяет цвет через `Image.color`. Это радикально снижает нагрузку на видеопамять и упрощает поддержку тем.
*   **AI-Assisted 9-Slice:** Автоматический расчет границ для Slice-спрайтов на основе анализа макета Figma.
*   **Asset Deduplication:** Глобальный поиск одинаковых ассетов по хешем для предотвращения дублей в проекте.

## 4. Agentic Orchestration (MCP Enabled)
Наш плагин становится первым в индустрии, поддерживающим протокол **Model Context Protocol (MCP)**.

*   **Internal MCP Server:** Плагин предоставляет API для ИИ-агентов, позволяя им выполнять команды:
    *   `SynchronizeScreen("MainMenu")`
    *   `ListFigmaComponents()`
    *   `AnalyzeLayoutIssues()`
*   **Automated QA:** ИИ-агент может автоматически проверить импортированный UI на наличие перекрытых Raycast-таргетов, некорректных шрифтов или потерю связей с префабами.
