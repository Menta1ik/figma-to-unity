# Figma to Unity Importer | Designer Guide v2.4.0 (Stencil Guard)

Данный инструмент предназначен для «пиксель-в-пиксель» переноса интерфейсов из Figma в Unity с использованием системы uGUI. Версия 2.4.0 фокусируется на стабильности масок (Stencil Guard), автоматическом «разглаживании» иерархии и поддержке сложных вложений.

---

## 🚀 1. Установка для разработчика (UPM)
Плагин теперь устанавливается через **Unity Package Manager** (UPM):
1. **Window -> Package Manager**.
2. **+ -> Add package from git URL...**.
3. Вставьте: `https://github.com/Menta1ik/figma-to-unity.git?path=/plugin`

---

## 🎨 2. Подготовка макета в Figma

### Нейминг и иерархия
* **Smart Sync**: Плагин ищет объекты по их **Figma ID**. Вы можете переименовывать слои в Figma или объекты в Unity — связь не разорвется.
* **Orphan Tracking**: Если вы удалите слой в Figma, в Unity объект не удалится физически, а будет помечен `[DELETED]` и выключен. Это защищает ваши скрипты от `MissingReferenceException`.

### Умные иконки (Smart Icons) & Flattening
Плагин автоматически объединяет сложные векторные группы в одну картинку, если:
1. Имя слоя содержит маркеры: `icon`, `img`, `avatar`, `illustration`, `logo`, `pic`.
2. Внутри группы **нет текстовых слоев** (это важно, чтобы текст оставался редактируемым).
*Результат*: Вы получаете чистую сцену с одним `Image`, а не сотни мелких векторов.

### Маркеры компонентов
Добавляйте суффиксы к именам фреймов/групп для авто-создания компонентов:
* `[Btn]` — добавит `Button` и настроит Raycast.
* `[Input]` — создаст `TMP_InputField`.
* `[Scroll]` — настроит `ScrollRect` и `Mask`.
* `_9slice` — (для спрайтов) автоматически настроит границы (borders) в Unity.

## 🛠 3. Работа в Unity (Dashboard)

Основной рабочий хаб доступен через: **Window -> Figma Importer -> Dashboard**.

### Ключевые функции v2.3.1:
* **Font Audit**: Перед импортом нажмите эту кнопку. Она проверит все шрифты в макете и сопоставит их с вашими `TMP Font Assets`. Если маппинга нет — импорт выдаст ошибку, предотвращая "битую" верстку.
* **Reskin Mode**: Позволяет обновить визуальную часть (цвета, спрайты, прозрачность) существующего окна, не меняя его структуру и не трогая логические скрипты.
* **Stencil Health**: В версии 2.4.0 маски стали «умными». Если плагин видит слишком глубокое вложение масок, он сам переключит их на `RectMask2D`, чтобы избежать ошибок отрисовки Unity.
* **Health Check**: Если что-то идет не так — используйте встроенный аудит: `Figma Importer -> Diagnostics -> Health Check (v2.4.0)`.

## ⚠️ Ограничения и советы
* **Opacity**: Плагин теперь корректно суммирует прозрачность слоя (Node Opacity) и прозрачность заливки (Fill Opacity).
* **Auto Layout**: Поддерживается нативно. Используйте `Auto Layout` в Figma — плагин создаст соответствующие `Vertical/Horizontal Layout Groups`.
* **Masks**: Маскирование в Figma (sibling mask) транслируется в Unity как `Parent Mask`. Группируйте маскируемые объекты внутри фрейма с маской.

## 🏗 4. Adaptive Layout & Constraints (v2.4.0)

В версии 2.4.0 плагин научился понимать «намерения» дизайнера относительно того, как интерфейс должен вести себя при изменении разрешения.

### Как использовать:
1.  **Constraints в Figma**: Настройте привязки (Left, Right, Scale, Center) для элементов внутри фреймов. Плагин автоматически создаст **Anchors** в Unity.
    *   *Совет*: Используйте **Scale**, если хотите, чтобы элемент растягивался пропорционально родителю.
2.  **Auto Layout**: По-прежнему поддерживается и имеет приоритет. Если на фрейме включен Auto Layout — плагин создаст `Horizontal/Vertical Layout Group`.
3.  **Root Canvas**: В настройках (`FigmaImporterSettings`) выберите `Canvas Scale Mode -> Scale With Screen Size`. Это позволит всему интерфейсу корректно масштабироваться под разные экраны (Mobile, Tablet, PC).
