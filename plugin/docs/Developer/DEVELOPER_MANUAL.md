# 🌌 Руководство разработчика: Antigravity Figma Importer v2.8.0

Это полное руководство по установке, настройке и эксплуатации промышленного пайплайна импорта UI из Figma в Unity uGUI. 

---

## 🛠 Шаг 1: Установка и зависимости

Плагин поставляется как автономный **UPM-пакет** (Unity Package Manager). 

### 1.1 Системные требования
*   **Unity 2021.3 LTS** (или новее).
*   **TextMeshPro**: должен быть инициализирован в проекте (`Window -> TextMeshPro -> Import TMP Essential Resources`).
*   **Newtonsoft JSON**: устанавливается автоматически как зависимость.

### 1.2 Установка через Git (Рекомендуется)
1. Откройте **Window -> Package Manager**.
2. Нажмите кнопку **+** (в левом верхнем углу) -> **Add package from git URL...**.
3. Вставьте ссылку:
   `https://github.com/Menta1ik/figma-to-unity.git?path=/plugin#v2.8.0`
4. Нажмите **Add**. Unity загрузит плагин и скомпилирует его.

---

## ⚙️ Шаг 2: Первичная настройка (Data Assets)

Перед запуском импорта необходимо создать два ключевых ассета в папке вашего проекта (`Assets/...`):

### 2.1 Создание настроек (Settings)
1. Нажмите ПКМ в окне Project -> **Create -> Figma Importer -> Settings**.
2. Назовите ассет `FigmaSettings`.
3. **Настройте пути (Asset Paths):**
   * `Base Sprites Path`: Папка для скачиваемых картинок (например, `UI/Generated/Sprites`).
   * `Base Prefabs Path`: Папка для готовых префабов (например, `UI/Generated/Prefabs`).
4. **Настройте логирование (Logging):**
   * `Log Level`: Установите `Minimal` для обычной работы или `Verbose` для глубокой отладки (выводит лог по каждой ноде).
5. **Экспорт изображений:**
   * `Image Export Scale`: Рекомендуется **2** для высокого качества (Retina).

### 2.2 Создание таблицы шрифтов (Font Mapping)
1. Нажмите ПКМ -> **Create -> Figma Importer -> Font Mapping Table**.
2. Этот файл связывает имена шрифтов из Figma (например, "Roboto Regular") с вашими ассетами **TextMeshPro SDF**.
3. Вы можете нажать кнопку **Font Audit** в окне плагина позже, чтобы увидеть список всех недостающих шрифтов.

## 🖥 Шаг 3: Работа с Dashboard (Инструкция по импорту)

Откройте окно через **Window -> Figma Importer -> Sync & Reskin Dashboard**.

### 3.1 Подключение к Figma
1. **Figma URL / File ID**: Вставьте ссылку на ваш макет.
2. **Access Token (PAT)**: Ваш токен из настроек аккаунта Figma. 
   > *Примечание: Токен хранится только в оперативной памяти сессии Unity и не попадает в Git.*
3. **Single Node ID**: Оставьте пустым для импорта всей страницы или вставьте ID конкретного фрейма (например, `147:572`) для быстрой синхронизации одного экрана.

### 3.2 Offline Mode (Локальный JSON)
Если вам нужно работать без интернета или вы скачали JSON вручную:
1. Положите файл в `Assets/lobby_figma.json`.
2. Включите галочку **"Use Local JSON"** в окне импортера.
3. Плагин проигнорирует сетевые запросы и соберет UI из этого файла.

### 3.3 Запуск синхронизации
1. Перетащите ваш **Root Canvas** из иерархии в соответствующее поле в окне плагина.
2. Нажмите зеленую кнопку **🚀 RUN FULL SYNC**.
3. **Batching Engine (v2.8.0)** автоматически разобьет запросы на порции по 25 объектов, предотвращая ошибку 414 (URI Too Long).

## 🏷 Шаг 4: Подготовка макета (Маркеры и Именование)

Чтобы Unity понимала, какие компоненты добавлять к объектам, используйте маркеры в именах слоев в Figma:

### 4.1 Функциональные маркеры
| Маркер | Результат в Unity | Описание |
| :--- | :--- | :--- |
| `[Btn]` | **Button** | Добавляет компонент Button и включает Raycast Target. |
| `[Input]` | **TMP_InputField** | Создает структуру для ввода текста. |
| `[Scroll]` | **ScrollRect** | Создает прокручиваемую область (нужен Mask/Content). |
| `[Toggle]` | **Toggle** | Добавляет компонент переключателя. |
| `[Img]` | **Image** | Принудительно скачивает ноду как спрайт (даже если это вектор). |

### 4.2 Графические маркеры
*   `_9slice` (в конце имени): Плагин автоматически настроит **Border** в Texture Importer и установит тип Image на `Sliced`.
*   `_mask`: Помечает слой как маску. Плагин использует `RectMask2D` или `Mask` в зависимости от вложенности.

## 🏗 Шаг 5: Технические особенности v2.8.0

### 5.1 Smart Sync (Неразрушающее обновление)
Плагин использует систему **паспортов (FigmaNodeId)**. Если вы добавили на объект в Unity кастомный скрипт или анимацию, они **не будут удалены** при повторном импорте. Плагин обновит только верстку (размеры, цвета, шрифты).

### 5.2 Stencil Guard (Защита от переполнения)
Unity имеет лимит глубины масок (8 уровней). Плагин:
1. Автоматически переключается на `RectMask2D` при глубине > 3.
2. Перед импортом выполняет `DismantleAll`, чтобы не плодить "контейнеры-матрешки" при повторных синхронизациях.

### 5.3 Batching Engine
Для огромных макетов с 500+ иконками плагин делает серию последовательных запросов по 25 штук. Это обходит лимиты серверов по длине URL (ошибка 414).

## 🔍 Шаг 6: Диагностика и Тестирование

### 6.1 Health Check (Аудит системы)
Если что-то не работает, перейдите в **Figma Importer -> Diagnostics -> Health Check**.
Нажмите **Run Full Audit**, чтобы проверить:
*   Целостность Assembly Definitions.
*   Наличие глобальных шрифтов.
*   Корректность работы Auto Layout транслятора.
*   Работоспособность системы Soft-Delete (Orphan tracking).

### 6.2 Unit Tests (58 тестов)
Для проверки стабильности в окне **Test Runner** (EditMode) доступны следующие наборы:
*   `DecompositionTests`: Проверка работы оркестратора и всех модулей (TreeWalker, MaskResolver).
*   `CacheTests`: Проверка файлового кэша API.
*   `HandlerTests`: Проверка создания всех типов UI компонентов.
