# 📋 Ответ на технический аудит и Дорожная карта v3.0

Этот документ является прямым ответом на проведенный аудит и содержит план устранения критических уязвимостей, а также интеграцию этих исправлений в архитектуру версии 3.0.

---

## 🛑 1. Заключение по аудиту

Проведенный аудит выявил **критические недостатки**, которые препятствуют использованию плагина в коммерческом продакшене высокого уровня. Мы полностью согласны с выводами и принимаем их как приоритетные задачи (Technical Debt) для перехода к v3.0.

### Статус подтвержденных проблем:
*   **Агрессивное удаление (High):** Подтверждено. Текущая логика `DestroyImmediate` несет риск потери данных (компонентов, скриптов) при ошибках связи.
*   **Шрифтовая рулетка (High):** Подтверждено. Использование первого попавшегося шрифта из базы — недопустимое поведение для системного UI.
*   **Конфликт с префабами (High):** Подтверждено. Необходима автоматическая распаковка (Unpack) или поддержка перевода в RectTransform.
*   **Производительность загрузки (Medium):** Подтверждено. Последовательная загрузка (serial) — «бутылочное горлышко» для сложных экранов.
*   **Заглушки (Reskin/Mask) (Medium):** Подтверждено. Функционал присутствует только в виде сигнатур методов.

## 🛠 2. План доработки: Phase 1 — Stability & Safety (Стадия Alpha)

Цель: Сделать импорт безопасным и предсказуемым.

### 2.1. Внедрение Safe Sync Mode
*   **Изменение:** Замена `DestroyImmediate` на `gameObject.SetActive(false)`.
*   **Новый компонент:** `FigmaOrphanedElement`. Он будет автоматически вешаться на деактивированные объекты.
*   **Визуальный маркер:** Добавление иконки-предупреждения ⚠️ в иерархии Unity для «осиротевших» объектов.
*   **Настройка:** Поле `Safe Delete Mode` в `FigmaImporterSettings` (включено по умолчанию).

### 2.2. Жесткая валидация шрифтов
*   **Изменение:** Если `GlobalFallbackFont` в настройках не задан — импорт прерывается с `EditorUtility.DisplayDialog`.
*   **Улучшение:** Окно аудита шрифтов будет выводить список всех шрифтов из Figma, у которых нет явного маппинга.

### 2.3. Интеллектуальная работа с префабами
*   **Логика:** При попытке изменить объект, являющийся частью префаба, плагин предложит:
    1.  Автоматически распаковать (Unpack).
    2.  Пропустить изменения.
    3.  Или (в перспективе v3.0) использовать систему переопределений (Overrides).

## ⚡ 3. Phase 2 — High-Performance Pipeline

Цель: Ускорение работы и реализация пропущенной логики.

### 3.1. Многопоточный загрузчик (Parallel Downloader)
*   **Реализация:** Использование `Task.WhenAll` для загрузки изображений.
*   **Троттлинг:** Лимит в 10 одновременных запросов через `SemaphoreSlim(10)` для защиты от блокировок Figma API.

### 3.2. Наполнение функционалом (Masks & Reskin)
*   **Masks:** Реализация `ApplyDeferredMasks`. Парсинг `isMask: true` и автоматическое добавление `Mask` / `RectMask2D`.
*   **Reskin:** Реализация `ReskinRecursive`. Обновление только визуальных данных (Sprites/Colors) без перестроения дерева Transform. Это критично для анимаций.

---

## 🎨 4. Phase 3 — Professional Features (v3.0 Core)

Цель: Полная замена ручной верстки.

### 4.1. Авто-Layout (Figma Auto Layout Bridge)
*   **Horizontal/Vertical Layout Groups:** Трансляция `layoutMode`, `padding`, `itemSpacing` и `counterAxisSizingMode`.
*   **Content Size Fitter:** Автоматическая настройка для текстовых блоков с динамическим контентом.

### 4.2. Продвинутый Slicing и иконки
*   **9-Slice Auto-Setup:** Если слой помечен как слайс, плагин сам выставит границы (`border`) в метаданных спрайта.
*   **Vector Content Handling:** Улучшенное определение векторных слоев для чистого экспорта.

---

## 🚀 5. Интеграция с Agentic Architecture (MCP)

Все новые функции безопасности и производительности будут доступны для ИИ-агентов через MCP инструменты:
*   `fix_layout_orphans`: Автоматическая очистка или восстановление «осиротевших» элементов.
*   `optimize_image_downloads`: Управление приоритетами загрузки через агента.
