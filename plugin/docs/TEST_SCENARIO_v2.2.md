# Сценарий проверки Figma Importer v2.1 (Standardized)

Этот документ описывает шаги для полной проверки работоспособности плагина "с нуля" после завершения процесса стандартизации (перевод на английский интерфейс и логов).

## 🛠 Подготовка
1. **Очистка данных**: (Уже выполнено) Удалены папки `Assets/Test`, `Assets/UI/Generated` и кэшированные настройки.
2. **Перезагрузка Unity**: Рекомендуется перезапустить Unity, чтобы обнулить кэш .asmdef и убедиться, что новые имена пространств имен и меню подхватились корректно.

---

## 📋 Шаги проверки

### Шаг 1: Инициализация настроек
1. В окне Project нажмите `Right Click -> Create -> Figma Importer -> Importer Settings`.
2. Назовите файл `GlobalFigmaSettings`.
3. В инспекторе настройте пути:
   - **Base Sprites Path**: `UI/Generated/Sprites`
   - **Base Prefabs Path**: `UI/Generated/Prefabs`
   - **Markers**: Убедитесь, что стоят стандартные `[Btn]`, `[Input]`, `[Scroll]`.

### Шаг 2: Первый импорт (Cloud Sync)
1. Откройте окно `Figma Importer / Sync & Reskin Dashboard`.
2. В блоке **Step 1: Figma Connection**:
   - Введите ваш **Access Token** и **File ID / URL**.
3. В блоке **Step 2: Data Source**:
   - Убедитесь, что галочка **Test Mode (Local JSON)** снята (работаем через Cloud по умолчанию).
4. В блоке **Step 3: Target Configuration**:
   - Создайте на сцене пустой Canvas (если его нет) и перетащите его в поле **Root Canvas**.
   - Перетащите созданный выше `GlobalFigmaSettings` в поле **Importer Settings**.
5. В блоке **Step 5: Execution**:
   - Нажмите **🚀 SYNC & GENERATE UI**.

**Ожидаемый результат:**
- В папке `Assets/UI/Generated/Sprites` должны появиться подпапки с именами экранов.
- На сцене должна построиться иерархия UI.
- В консоли должны быть логи с префиксом `[FigmaImporter]` на английском языке.

### Шаг 3: Проверка интерактивности
1. Найдите объект, у которого в Figma было имя `[Btn] MyButton`.
2. Убедитесь, что на нем висят компоненты `Image` и `Button`.
3. Убедитесь, что `Raycast Target` выключен у дочерних текстов и иконок (проверка работы `InteractiveHandler`).

### Шаг 4: Проверка шрифтов
1. Выберите любой текстовый объект.
2. Проверьте, что в поле `Font Asset` назначен корректный шрифт.
3. Проверьте консоль на наличие предупреждений `Font not found` — они должны быть информативными и на английском.

### Шаг 5: Проверка Reskin (Experimental)
1. В окне импортера в самом низу включите **Dev Mode**.
2. Появится секция **♻️ Reskin Area (Experimental)**.
3. Выберите импортированный UI-виджет на сцене и перетащите его в поле **Target Prefab/Obj**.
4. Введите ID **другого** аналогичного узла из Figma в поле **New Figma ID**.
5. Нажмите **🎨 Perform Reskin**.

**Ожидаемый результат:**
- Виджет на сцене обновил спрайт и цвета, но сохранил свои Unity-связи.

## 🚦 Критерии успеха
- [ ] Интерфейс окна полностью на английском (labels, tooltips, helpboxes).
- [ ] В консоли нет русских слов в логах и ошибках.
- [ ] Все пути к ассетам соответствуют настройкам в `Importer Settings`.
- [ ] Документация в `docs/` соответствует актуальному состоянию UI.
- [ ] Утилиты в меню `Figma Importer / Utilities /` работают и имеют English UI (AABBSniper, NaNDetector).
