## 1. Executive Summary
**Front-Strike** — тактический многопользовательский шутер нового поколения, объединяющий классический соревновательный геймплей с современными технологиями рендеринга и децентрализованной экономикой.

## 2. Gameplay & Mechanics
### 2.1 Core Loop
- **Prepare:** Экипировка в Арсенале, подключение кошелька.
- **Engage:** Тактический бой в составе отряда.
- **Extract:** Получение наград, подтверждение транзакций.

### 2.2 Combat System
- **Precision Gunplay:** Акцент на хэдшоты (уникальные визуальные уведомления).
- **Armor Layers:** Слоистая система защиты (Armor vs Health).
- **Abilities:** (TBD) — возможные гаджеты операторов.

## 3. UI/UX (Based on Figma)
### 3.1 Lobby & Social
- **Squad System:** Поддержка групп, визуальное отображение статуса готовности и микрофона.
- **Select Mode:** Выбор между тренировкой, ранговым матчем и специальными событиями.

### 3.2 Armory
- **Rarity System:** Common (серый), Rare (синий), Epic (фиолетовый — *внимание: Purple Ban на UI, только для индикации редкости*), Legendary (золотой).
- **Filters:** По типу оружия, по редкости, по состоянию.

## 4. Web3 Integration
- **Wallet Login:** Основной метод входа для доступа к инвентарю.
- **Marketplace Interface:** Возможность покупки/продажи скинов напрямую из игры.

## 5. Technical Architecture
### 5.1 Rendering (URP + Compute)
- **Shader Strategy:** Использование `SetAlphaChannel.compute` для постобработки и Path Tracing элементов.
- **Performance:** Оптимизация под мобильные устройства и десктоп.

### 5.2 Project Structure
- **Scripts:** Чистая логика (C#), ScriptableObjects для данных оружия.
- **Prefabs:** Модульные UI компоненты на основе Figma-дизайна.
