# 🎨 Figma Direct Importer v1.1.1 (uGUI)

Этот инструмент обеспечивает «пиксель-в-пиксель» перенос интерфейсов из Figma в Unity с использованием системы uGUI. Плагин работает на базе Content-Aware логики, автоматически распознавая типы объектов и оптимизируя загрузку графики.

## 📋 Требования (Prerequisites)
Перед установкой убедитесь, что в Unity-проекте установлены:
* **Newtonsoft Json (Json.NET)**: для парсинга данных Figma API.
* **TextMesh Pro**: все текстовые узлы создаются как `TextMeshProUGUI`.
* **Папка Editor**: файл `FigmaDirectImporter.cs` должен находиться в папке `Editor` (например, `Assets/Scripts/Editor/`).

## 🎨 Гайд для дизайнеров (Figma Preparation)
### Нейминг и структура
* **Осмысленные имена**: названия слоев станут именами объектов в Unity (`btn_deploy`, `txt_player_name`).
* **Скрытые слои**: выключенные объекты игнорируются при импорте.

### Текст и шрифты
* **Шрифт**: Рекомендуется **Barlow Condensed** для корректного маппинга.
* **Регистр**: Поддерживается настройка Uppercase.
* **Weights**: Поддерживаются числовые веса (100–900). Настройте таблицу Font Weights в ассете TMP.

### Умные иконки (Smart Icons)
Если компонент не содержит текстовых слоев, плагин считает его «Иконкой» и скачивает как единую PNG-картинку (Retina 3x).

## 💻 Гайд для разработчиков (Workflow)
### Шаг 1: Настройка подключения
1. Введите **Access Token** и **File ID**.
2. **Node ID (ОБЯЗАТЕЛЬНО)**: указывайте ID конкретного экрана (фрейма).
3. **Global Font**: назначьте основной TMP Font Asset.

### Шаг 2: Управление Layout
* **Import Figma Auto Layout (OFF)**: Рекомендуется для статических экранов (Лобби). Обеспечивает точность координат.
* **Import Figma Auto Layout (ON)**: Только для структур, требующих динамики.

### Шаг 3: Процесс сборки
1. **ANALYZE LAYOUT**: проверка структуры через API.
2. **BUILD UI**: создание иерархии объектов на сцене.
3. **FORCE SYNC IMAGES**: скачивание и настройка спрайтов.
