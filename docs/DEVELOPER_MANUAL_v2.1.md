# 🛠 Руководство разработчика: Figma Importer v2.1

Данный документ описывает процесс настройки, использования и расширения системы импорта интерфейсов из Figma в Unity.

## Step 0: Подготовка ассетов (Первый запуск)

Если вы устанавливаете плагин впервые, вам необходимо создать файлы настроек:

1.  **FigmaImporterSettings**: В папке `Assets` (рекомендуется `Assets/Game/Settings/`) нажмите правую кнопку мыши -> **Create -> Figma Importer -> Settings**. Назовите файл `FigmaImporterSettings`.
2.  **FontMappingTable**: Там же нажмите правую кнопку мыши -> **Create -> Figma Importer -> Font Mapping Table**. Назовите файл `FontMappingTable`.
3.  **TextMeshPro**: Убедитесь, что в проекте установлен TextMeshPro, так как плагин использует его для всех текстовых элементов.

---

## Step 1: Connection & Config

В этом блоке настраивается связь с вашим проектом в Figma.

1.  **Figma URL / File ID:**
    *   В Figma: Нажмите синюю кнопку **Share** в правом верхнем углу.
    *   Нажмите **Copy link**.
    *   Или выберите конкретный экран (Frame) -> Правая кнопка -> **Copy/Paste as** -> **Copy link** (это ускорит импорт только одного экрана).
2.  **Access Token (PAT):** 
    *   Зайдите в настройки Figma -> **Personal access tokens** -> **Generate new token**.
3.  **Importer Settings:**
    *   Перетащите сюда ассет настроек, созданный на **Step 0**. Здесь указываются пути для сохранения префабов и ресурсов.

---

## Step 2: Resources & Target

Связывание ресурсов Figma с ассетами Unity.

1.  **Font Mapping:** перетащите сюда вашу таблицу шрифтов. 
    *   Нажмите **Font Audit**, чтобы проверить, все ли шрифты из Figma имеют соответствие в Unity.
2.  **Root Canvas:** Перетащите ваш **Canvas** (или пустой объект внутри него) из иерархии сцены. 
    *   *Важно: Плагин будет строить UI именно внутри этого объекта.*

---

## Step 3: Sync & Generate

Запуск процесса импорта.

1.  **Sync Images:** включите, если нужно скачать спрайты.
2.  Нажмите зеленую кнопку **🚀 RUN FULL SYNC**.
3.  **Результат:** Плагин автоматически создаст или обновит префаб в папке, указанной в ваших настройках (Step 0).

## Utilities (Полезные инструменты)

Внизу окна расположены дополнительные инструменты:
- **Clear Root Canvas:** Удаляет все дочерние объекты из выбранного Root Canvas. Полезно перед началом чистого импорта.
- **Show Dev Tools:** Открывает доступ к отладочным функциям для разработчиков плагина.

## Рекомендации по именованию (Markers)

Используйте суффиксы в названиях слоев Figma для автоматизации компонентов в Unity:
*   `[Btn]` — создает компонент `Button`.
*   `[Input]` — создает `TMP_InputField`.
*   `[Scroll]` — создает `ScrollRect`.
*   `[Toggle]` — создает `Toggle`.

> [!IMPORTANT]
> Никогда не удаляйте компонент `FigmaElement` с объектов. Он является "паспортом" объекта и необходим для работы Smart Sync.

## 📦 Сборка и распространение (Distribution)

Плагин полностью совместим со стандартом **Unity Package Manager (UPM)**.

### Как перенести плагин в другой проект:
1.  **Add from disk:** В новом проекте откройте `Package Manager`, нажмите `+` -> `Add package from disk` и выберите `package.json` из папки `com.figmaimporter.v2`.
2.  **Add from Git:** Если вы загрузите папку пакета в Git-репозиторий, ее можно будет устанавливать через `Add package from git URL`.
3.  **Локальная копия:** Вы можете просто скопировать папку `com.figmaimporter.v2` в папку `Packages/` вашего нового проекта.
