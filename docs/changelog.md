# Changelog

Все заметные изменения в проекте **Figma Direct Importer** будут фиксироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
и проект придерживается [Семантического Версионирования](https://semver.org/spec/v2.0.0.html).

## [1.1.1] - 2026-04-15

### Добавлено
- **Первый публичный релиз** инструмента Figma Direct Importer для Unity (uGUI).
- **Smart Icons**: автоматическое распознавание слоев без текста как иконок и их экспорт в Retina 3x.
- **TextMesh Pro Support**: полная поддержка текстовых стилей, начертаний и регистра (Uppercase).
- **Auto Layout Support**: возможность опционального импорта структур с Auto Layout.
- **Designer Guide**: подробные инструкции по неймингу и подготовке макетов в Figma.
- **Workflow Developer**: пошаговый процесс импорта через Analyze, Build и Sync.
- **Pixel-Perfect Alignment**: точное позиционирование элементов по координатам из Figma API.
